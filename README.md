# Goro Survivor

吾郎さんの `pets` スプライトを使った見下ろし型ローグライク・ゾンビサバイバーです。
A famous man Goro's game.

## 遊び方

- `index.html` をブラウザで開く


## 操作

- `WASD` / 矢印キー: 移動
- `Space`: ダッシュ
- `P`: 一時停止

## ルール

- 攻撃は近い敵へ自動射撃
- ゾンビを倒すと経験値とコインを落とします
- レベルアップごとに3択の強化を選びます
- 10分間生き残るとクリアです
